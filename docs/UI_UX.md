# UI_UX.md — 공통 UI/UX

## 목표
작업자는 현장에서 빠르게 입력하고, 관리자는 많은 데이터를 빠르게 판단하며, 공무/기성 담당자는 근거를 역추적할 수 있어야 한다.

## 사용자
- 작업자: 사진/일보/수량/인원
- 현장관리자: 승인/공정/작업실적
- 공무·기성: 계약 ITEM/기성/증빙

## 기본 구조
Header → Context → KPI → Filter → Main Data → Detail/Action

## 입력
- 터치 영역 44px 이상 권장
- 숫자 입력은 숫자 키패드
- 반복 항목은 행 추가
- 음성입력은 보조수단
- 저장과 제출 분리
- 오류는 이해하기 쉬운 문구

## 상태
승인 Approved / 검토중 Pending / 반려 Rejected / 확정 Confirmed
색상만 사용하지 말고 텍스트/아이콘을 함께 사용한다.

## 브랜드
기존 네이비/블루 계열을 유지한다.
Primary #1E3A5F / Secondary #2E5F9E

## 원칙
한 화면의 주 목적을 명확히 하고 현장 입력은 최소 단계, 관리자 검토는 필터·요약·상세 연결을 제공한다.
