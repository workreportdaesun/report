# UI_PAYMENT.md — 단기기성 화면

## 목적
단기기성은 단순 금액 입력이 아니라 승인된 작업실적을 계약 ITEM에 연결하고 수량·단가·증빙을 검증하는 화면이다.

## 상단 KPI
기성기간 / 계약금액 / 전회누계 / 금회기성 / 누계기성 / 잔여금액

## 단계
기성대상 → 검토 → 증빙 → 확정
상태: 작성 → 자료수집 → 검토 → 증빙확인 → 기성확정 → 마감

## 메인 테이블
ITEM | TAG | 계약량 | 전회누계 | 금회량 | 누계량 | 잔량 | 단가 | 금회금액 | 증빙상태

## 상세
계약정보 → 작업실적 → 작업일보 → 작업일/팀 → 작업사진 → 승인 → 기성수량 → 단가 → 금액 → 증빙

## 계산
누계수량 = 전회누계 + 금회수량
잔량 = 계약수량 - 누계수량
금회금액 = 금회수량 × 적용단가
초과수량은 별도 표시

## 규칙
미승인 작업 제외, 미매칭 ITEM 검토, 계약수량 초과 경고, FCN/변경 분리, 원천 작업일보와 사진까지 역추적 가능.

## 추적
기성금액 → 기성수량 → 계약 ITEM → 작업실적 → 작업일보 → 작업일/팀 → 작업사진
