# UI_MOBILE.md — 모바일 현장 기준

## 대상
작업자 앱은 360~480px 폭을 기준으로 한다.

## 공통
주요 버튼 44px 이상, 한 손 조작, 넓은 테이블 강제 축소 금지, 핵심 입력 상단 배치, 삭제와 저장/제출 분리.

## 일보
작업일/사용자/팀 → 작업분류 → TAG → 규격/수량/진도 → 사진 → TBM → 명일 작업 → 자재요청 → 저장 → 제출

## 사진
촬영 → 분류/구역 → 저장 → 작업일보 연결
썸네일은 2~4열.

## 관리자 모바일
테이블보다 요약 카드 → 상세 화면을 우선한다.

## 기성 카드
ITEM/TAG / 계약수량 / 전회누계 / 금회수량 / 누계수량 / 잔량 / 금액 / 증빙상태 / 상세
