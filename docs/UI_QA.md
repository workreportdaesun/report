# UI_QA.md — 화면 검증

## 공통
로그인/권한, 메뉴 이동, 새로고침, 콘솔 오류, 중복 저장/제출, 빈 데이터, 반응형을 확인한다.

## 작업일보
분류, TAG, 수량, 사진, TBM, 임시저장, 제출, 승인/반려를 확인한다.

## 공정
계획, 전일누계, 금일, 누계, 잔량, 공정률의 계산 일관성을 확인한다.

## 테이블
검색, 필터, 정렬, 합계, 상세, 긴 텍스트, 대량 데이터, 모바일 카드 전환을 확인한다.

## 기성
승인 작업만 반영 / 계약 ITEM 매칭 / 전회+금회=누계 / 계약-누계=잔량 / 초과 표시 / 단가·금액 / 증빙 / FCN 분리 / 마감 수정 제한을 확인한다.

## 반응형
360 / 390 / 430px 및 데스크톱에서 버튼, 입력, 테이블, 카드, 모달, 스크롤을 확인한다.
